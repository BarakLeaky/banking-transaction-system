# Banking Transaction System

A full-stack starter banking transaction project built for learning and extension.

## Stack
- Backend: Node.js, Express, SQLite, JWT authentication
- Frontend: React + Vite
- Database: SQLite
- Currency: KES

## Features
- Register and login
- Create bank accounts
- Deposit funds
- Withdraw funds
- Transfer funds
- Delete dormant/zero-balance accounts
- Create a loan account
- Disburse a KES 10,000 starter loan
- Transaction history
- Dashboard balances

## Requirements
Install Node.js 18+.

## Run backend
```bash
cd backend
npm install
copy .env.example .env
npm run dev
```

On macOS/Linux:
```bash
cp .env.example .env
```

Backend runs on http://localhost:5000

## Run frontend
Open another terminal:
```bash
cd frontend
npm install
npm run dev
```

Open the Vite URL shown in the terminal, normally http://localhost:5173.
